# README.md

## Project Development

This section outlines the project site-up and coding standards for my static
solo music site.

### Templates

The project uses Liquid templates for pages. Until there are requirements for
more complex templates, this is the formatting I'm sticking with.

Blog functionality uses Markdown files.

### Formatting

For formatting prettier is used. The WebStorm IDE is used for development and is
configured to apply prettier formatting on save.
